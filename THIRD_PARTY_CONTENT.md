---

## 2. Resource Descriptions & Metadata

- Descriptions and metadata cataloged in this repository are compiled from publicly accessible primary sources (official documentation, project homepages, code repositories, package registries, and research papers) or authored independently to describe technical capabilities objectively.
- External code snippets in Developer Quick Starts are minimal illustrative examples intended to demonstrate basic API invocations in accordance with official documentation.
