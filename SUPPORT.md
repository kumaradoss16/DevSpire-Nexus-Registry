# Getting Support for DevSpire Nexus Registry

Thank you for using DevSpire Nexus Registry! Here are the best ways to get help:

## Community & Discussions

- **GitHub Issues:** Use GitHub Issues for bug reports, schema enhancement suggestions, or resource corrections:
  - Submit a new resource: Use the [New Resource Submission Template](.github/ISSUE_TEMPLATE/resource_submission.yml)
  - Propose metadata updates: Use the [Resource Update Template](.github/ISSUE_TEMPLATE/resource_update.yml)
  - Report a bug in the CLI/validator: Use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml)
- **Website:** Browse the visual directory at [DevSpire Nexus](https://devspirehub.com).

## Security Inquiries

For sensitive or security-related matters, please review our [Security Policy](SECURITY.md) and contact `security@devspirehub.com`.
